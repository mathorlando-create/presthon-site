# presthonrock.com.br

Site oficial da Presthon, publicado pelo GitHub Pages.

Este repositório guarda só o site pronto (gerado). O código-fonte, os textos e as imagens originais ficam na pasta do projeto (`SITE_PRESTHONROCK/presthon-site`). Para atualizar: edite em `content/`, rode `python3 build.py` e substitua os arquivos daqui pelo conteúdo de `dist/`, mantendo `CNAME`, `.nojekyll` e este README.

Desenvolvido por Orlando Marketing e Branding.
